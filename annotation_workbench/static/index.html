结束时间不包含在采样中。每个片段初始对应一个场景，可在帧级面板统一调整。原帧不经清晰度筛选。

标注规则

  • 以物理文字行为条目；OCR 的拆框不等于多个条目。
  • ID 在任务内唯一，跨帧沿用。不同任务可用“任务 ID / 条目 ID”唯一引用。
  • 遮挡不改变内容版本；追加、擦除、重写需新建版本。
  • 同一条目可包含多个可见区域。完全遮挡时清空可见区域与可见文字。
  • “可见文字”只写当前帧能读到的内容；版本文字可记录已确认的完整内容。
  • 参考帧可手动选择，变化标签只对这个明确帧对生效。
  • 画多边形：逐点点击，Enter 完成，Esc 取消。选择模式下可拖动顶点和整个区域。
  • OCR 是未确认预测；接受后仍须核验。完成一帧前请确认全部条目与帧级核验。
  • 拆分：先给当前条目画保留区域，再新建另一文字框；合并：选择多个条目，点击合并。
