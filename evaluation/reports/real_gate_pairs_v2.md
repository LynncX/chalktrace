# 真实帧对：变化组件验证

日期：2026-11-08。标注：[gate_pairs.yaml](../annotations/gate_pairs.yaml)。本报告只检查无遮挡文字 ROI 上的变化组件，假定参考帧已经完成 OCR；不执行人体检测或 OCR，不把策略放行数称作 OCR 调用数。

## 结果

| 样本 | 类型 | SSIM | 灰度变化比例 | 决策 | 符合标注 |
|---|---|---|---|---|---|
| 标题 0→5 秒 | 静态 | 0.985776 | 0.004367 | unchanged，跳过 | 是 |
| 标题 5→10 秒 | 静态 | 0.987296 | 0.000496 | unchanged，跳过 | 是 |
| 第一行 50→52 秒 | 静态 | 0.990765 | 0.000054 | unchanged，跳过 | 是 |
| 第一行 47→50 秒 | 新增定义文字 | 0.836430 | 0.062500 | changed，放行 | 是 |
| 第一行 52→54 秒 | 新增 which manipulates | 0.878416 | 0.051398 | changed，放行 | 是 |
| 440→450 秒 | 讲课场景切换 | 0.452560 | 0.369501 | changed，放行 | 是 |

六个帧对中，三个静态样本跳过，两个新增样本和一个场景切换放行；实际 OCR 调用为 0。这里不是六段完整流水线的召回/精度评测，也不是独立测试集。第一个静态样本的 SSIM 接近默认阈值 0.985，说明压缩噪声与阈值敏感性仍值得扩大样本检查。

## 首轮选区错误的核查

首轮 `real_gate_pairs_v1` 中，50→52 秒样本的 ROI 为 `[260,20,1000,60]`。52 秒教师头顶进入 ROI 底部，导致 changed，首轮吻合 5/6。它不能被标为“无遮挡静态文字”。

修正后的 ROI 为 `[260,20,1000,45]`，下缘限定在原帧 y=64，排除教师头部。门控代码与阈值未改变；复测吻合 6/6。首轮结果与标注快照仍在对应实验目录，不能把这次改善归因于算法升级。

## 覆盖边界

- 这份视频由多段画面拼接而成，换场景不等于真实擦除；当前没有可靠的真实擦除标注。
- 擦除判定增加了单独的合成单元测试：原有墨迹消失也应触发 changed；它不能替代真实擦除视频。
- ROI 为人工挑选的无遮挡文字区域。本报告验证变化组件，不证明全板门控能处理持续遮挡、镜头移动或短暂板书。
- 不调整阈值追求这六个样本全过，不报告 CER、OCR 准确率或全文召回。
