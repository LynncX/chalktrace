# 算法环境与冒烟测试

依赖由根目录 `../pixi.toml` 和 `../pixi.lock` 管理。OpenCV 仅保留 PyPI 的 `opencv-contrib-python`，不同时安装 Conda OpenCV 或其他 OpenCV wheel。

在项目根目录执行：

```sh
pixi install --locked
pixi run ocr-smoke --help
pixi run ocr-smoke --seconds 120
pixi run python -m workbench.build --run ocr_smoke --assets inline
```

默认视频为 `../data/videos/test_video.mp4`；也可传入 `--video`、`--seconds` 和 `--run-id`。时间参数指视频绝对时间点。测试使用 CPU 上的 `PP-OCRv5_server_det` 和 `PP-OCRv5_server_rec`，关闭文档方向、文档矫正和文本行方向辅助模型，首次执行需要下载权重。

Pixi 激活时通过 `PIXI_PROJECT_ROOT` 将 PaddleX 模型、Hugging Face 与 XDG 缓存定位到项目的 `../.cache/`。该目录已被 Git 忽略；删除后会按需重新下载。环境本身在 `../.pixi/`，测试产物在 `../runs/ocr_smoke/`，均与系统 Python 隔离。

测试只执行单帧抽取与 OCR，并通过现有 RunWriter 写 manifest。原帧、编号框叠加图、逐框多边形／文字／置信度、调用耗时均保留。其他算法阶段保持 pending；冒烟通过只表示推理链路可用，不代表中文板书识别质量达标。
