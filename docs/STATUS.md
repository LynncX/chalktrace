# 项目状态

更新：2026-11-09 · 分支：`feat/algorithm` · 算法基准提交：`817841f`

当前已跑通固定机位、人工白板标定下的算法最小闭环：视频 → 抽帧 → 区域校正 → 遮挡/变化门控 → 增强 → OCR → 跨帧条目 → 带证据的去重笔记。可通过 CLI 执行，工作台读取运行产物进行核验；已接通本地单用户 Web 最小闭环：上传、预览与 ROI 框选、任务进度、视频/条目证据联动、Markdown / TXT 下载；`pixi run serve` 启动，默认端口 8001。

## 已完成

| 模块 | 当前状态 |
|---|---|
| 环境 | Pixi 管理依赖，保留 PyPI OpenCV，模型与缓存放在项目 `.cache/` |
| 01 抽帧 | 固定间隔采样、清晰度筛选、实际帧号与时间戳落盘 |

| 04 门控 | 遮挡优先、共同可见区变化检测、可见区域恢复、冷却与定时刷新；可与固定采样比较 |

| 07 条目 | 位置＋文本相似度匹配、较完整版本择优、首末观察时间及全部识别历史 |

| 人工标注工作台 | 本地服务，固定片段帧集、OCR 预标注、区域编辑、跨帧身份与内容版本、遮挡与帧对标签、自动保存和 JSON 导出；`pixi run annotate` 启动 |

## 当前限制与下一步

- 依赖固定机位、固定人工标定；尚无自动白板定位、移动机位适配和专门的切镜头处理。
- 遮挡是人体框覆盖估计，门控仍可能漏掉短暂板书；尚无充分的真实擦除与中文板书评测。
- 条目匹配为行框级启发式，尚未解决一对多拆行/合行及擦除重写；“最佳版本”不保证文字正确，观察时间不等于书写起止时间。
- 教师身份/朝向/行为统计、自动纠错、PDF 导出、课程管理和远程多用户部署尚未完成；当前 Web 为本地单用户最小版本。
- 下一步在标注工作台完成首批试标，稳定规范后扩展到 30–50 帧；接入标注评测并处理拆行/合行残余重复，再补真实擦除、中文素材，并逐步迭代已接通的 Web 产品。当前 `whiteboard_pilot` 为 140–170 秒的 6 帧待标任务，人工条目尚为空。
